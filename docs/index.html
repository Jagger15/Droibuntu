Update from Droibuntu

  1. Open Settings → Updates → Droibuntu APK updates.
  2. Set the GitHub repository to Jagger15/Droibuntu.
  3. Check for a release, download and verify, then confirm installation in Android.

Current update checks are manual. APKs must have a newer version and the same signing certificate.

Follow the project

Each release includes its APK, corresponding public source and checksums. Test builds remain experimental; hardware behavior needs testing on each device.
